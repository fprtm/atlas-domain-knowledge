# Atlas Domain Knowledge

Kamus referensi dunia nyata untuk programmer, product builder, dan pebisnis.

Kerangka untuk memetakan pengetahuan dunia nyata (industri, organisasi, peran,
proses, sistem, data, aturan, teknologi) menjadi struktur yang bisa dipakai untuk
product discovery, system design, knowledge graph/ontology, dan pemetaan use case AI.

- **Dokumen:** [atlas-domain-knowledge.md](atlas-domain-knowledge.md)
- **Versi:** 1.0 — 22 Agustus 2026
- **Status:** Living reference / extensible ontology
